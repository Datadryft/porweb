# Building a Blog within a 3D Portfolio

Welcome to the newly integrated Neural Logs! 

Here, you can read articles without ever leaving the main application. This seamless transition ensures a consistent user experience while maintaining the immersive 3D background.

## Features
- **Markdown Support:** Write easily using standard markdown.
- **GitHub Flavored Markdown:** Includes support for tables, strikethrough, and more natively via `remark-gfm`.
- **Embedded Media:** Render images, tables, and text beautifully!
